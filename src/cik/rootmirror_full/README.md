# CIK RootMirror Full

CIK v0.5 Full RootMirror Verification Layer.

This package verifies local run-envelope continuity:

1. Captures a pre-run root anchor.
2. Captures a post-run root anchor.
3. Measures ledger append delta.
4. Discovers expected artifacts.
5. Hashes artifacts.
6. Computes output-root hash surface.
7. Emits RootMirror full JSON, Markdown, and evidence package.
8. Preserves the non-claim lock: continuity is not correctness.

RootMirror full does not prove code correctness, semantic truth, security, supply-chain provenance, intelligence, consciousness, or autonomous memory.
