# CIF v2.1 Summary for CIK

CIK implements the CIF v2.1 instrumentation loop:

    Anchor -> Shape -> Measure -> Weight -> Stress -> Classify -> Fossilize -> Verify -> Index -> Interpret

CIK v0.1 implements this loop minimally. The active instrument is `rcc-drift`.

## Current CIF maturity

CIK v0.1 is classified as CIF4 because it emits artifacts.

It is not CIF5, CIF6, CIF7, or CIF8 because perturbation testing, RootMirror verification, Tesseract indexing, and reusable cross-domain instrument evidence are not yet complete.
