# CIK v0.9 Dashboard Contract

## Purpose

CIK v0.9 emits static dashboard-ready JSON and Markdown.

Required outputs:

- `outputs/dashboard/dashboard_data.json`
- `outputs/dashboard/dashboard_report.md`
- `outputs/dashboard/release_readiness_summary.md`

## Static local-first lock

The dashboard must be static and local-first. It must not require a server, cloud API, browser app, database, or live monitoring process.

## Non-claim boundary

Dashboard is navigation, not truth.

Visualization is not validation.

Release-readiness is not release proof.

Ready status is not a public guarantee.
