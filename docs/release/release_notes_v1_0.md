# CIK v1.0 Release Notes

CIK v1.0 is the Stable Local-First Release of the Codex Instrumentation Kernel.

## Release purpose

CIK v1.0 locks the validated v0.6-v0.9 stack into a stable local-first release surface.

## Included layers

- v0.6 core scoring, maturity, downgrade, and registry governance.
- v0.7 orchestration and evidence composition.
- v0.8 evidence graph and cross-run query.
- v0.9 full Tesseract and dashboard-ready package.
- v1.0 stable release bundle, checklist, validation surface, and non-claim lock registry.

## Non-claim boundary

CIK v1.0 does not prove truth, correctness, security, provenance, intelligence, consciousness, autonomous memory, or external validation.
